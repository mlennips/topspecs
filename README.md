# topspecs
Generische Verwaltung von Gegenständen und deren Spezifikationen (Assets,
Components, Specs) mit KI-optimiertem Sharing über ShareLinks.

## Architektur
Clean Architecture, Vertical Slices, CQRS, zwei Bounded Contexts
(Inventory, Templates). Vollständige Dokumentation: [docs/TopSpecs-arc42-V1.md](docs/TopSpecs-arc42-V1.md)

## Tech-Stack
.NET · ASP.NET Core · EF Core + PostgreSQL (JSONB) · Angular · Microsoft Entra External ID · .NET Aspire
